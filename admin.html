🔗 Correspondance Hiboutik

Associe chaque produit de la carte et chaque option (sauce, croquant, coulis...) à son ID Hiboutik (visible dans l'URL de sa fiche produit). Vide = non transmis à Hiboutik lors de l'encaissement.
📋 Marche à suivre pour un nouveau produit ou une nouvelle sauce :

1. Crée-le dans ta carte (Excel réimporté, ou réglages admin habituels) — il aura un nouvel ID (ex: b36, s8...).
2. Crée le même produit dans Hiboutik — même nom exact, même prix (0€ pour une sauce/option gratuite), bonne TVA (10% nourriture/soft, 20% alcool). Note son ID Hiboutik (visible dans l'URL de sa fiche produit).
3. Renseigne la correspondance ici — le nouveau produit apparaît automatiquement dans la liste ci-dessous (champ vide). Tape son ID Hiboutik à côté. Sauvegarde automatique, rien d'autre à faire.
4. Teste — commande avec ce produit, encaisse, vérifie qu'il apparaît bien dans Hiboutik avec le bon prix.

⚠️ Pour une sauce/option (famille "Sauce") : le rapprochement se fait sur le nom exact (insensible à la casse) entre le choix du client et le nom du produit Hiboutik — pas besoin de toucher au code tant que les noms correspondent mot pour mot.

Import

Import Excel

Remplacez toute la carte à partir d'un fichier.

Format attendu — colonnes dans l'ordre :
A: ID · B: Catégorie · C: Nom · D: Description · E: Emoji · F: Prix EUR · G: Actif (OUI/NON) · ... · J: ID Hiboutik (optionnel) · K: Cuisine (OUI/NON, optionnel) · L: Libellé cuisine (optionnel)

🍳 Colonnes "Cuisine" : mets OUI en colonne K pour qu'un produit s'affiche dans l'onglet Cuisine de la caisse (un nouveau produit est ainsi pris en compte dès l'import, sans rien cocher ici). Colonne L : nom de regroupement facultatif (ex. « Nuggets » pour regrouper poulet + poisson). NON retire le produit de la cuisine. Case vide = on garde le réglage fait dans l'admin. Les plats du menu enfant se cochent à la main (Carte → Menu enfant → clique le plat).

Catégories valides : formules · sauces · softs · bieres · vins_blancs · vins_roses · vins_rouges · cocktails · sangria · desserts · digestifs · chauds

🔗 Colonne "ID Hiboutik" : si elle est remplie (dernière colonne de chaque onglet produit, et de l'onglet Familles Options), la Correspondance Hiboutik est mise à jour automatiquement à l'import — plus besoin de la ressaisir à la main dans l'écran "🔗 Correspondance Hiboutik".

🧒 Colonne M "Enfant gratuit" (facultative) : ADULTE = ce menu ouvre droit à 1 enfant gratuit · GRATUIT = menu enfant gratuit (1 par menu adulte) · NON = hors règle · case vide = on garde le réglage de l'admin (Réglages → Règle « enfant gratuit »).

🗂️ Onglet "Catégories" (fichiers créés par l'Import de carte IA) : s'il est présent, il fixe les tuiles du client, leurs titres, leurs emojis et leur ordre (ex. 🍕 Pizzas, 🥞 Galettes). Sans cet onglet, les catégories habituelles de Moule & Smile sont utilisées.

⚠️ L'import remplace toute la carte. Utilisez MouleSmile_Carte_Admin.xlsx comme base.

🖨️ Imprimer la carte du restaurant

Édite la carte A4 (2 pages) à partir de la carte publiée, avec les prix affichés aux clients et les mentions obligatoires :
• prix nets, service compris, TTC
• suppléments payants des options (croquant, coulis, nappage…) imprimés sous chaque produit avec leur prix ; choix à 0 € imprimés en « au choix »
• allergènes (14) disponibles sur demande · carafe d'eau gratuite
• alcool : abus dangereux pour la santé, interdit aux mineurs, grossesse
• médiateur de la consommation (à compléter dans la page)
Seuls les produits actifs sont imprimés. Un bouton permet aussi de télécharger la carte en Excel.
