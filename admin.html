🔒 Sécurité — WiFi & Token

Configurez le nom de votre réseau WiFi et le token de sécurité.
Les clients verront le nom du WiFi sur l'écran de blocage.
Affiché aux clients qui ne sont pas sur le WiFi du restaurant
⚠️ Après changement → régénérer les QR codes dans qrcodes.html
Comment ça marche :
1. Changez le nom WiFi → les clients voient le bon réseau sur l'écran de blocage
2. Changez le token chaque saison → anciens QR codes deviennent invalides
3. Regénérez les QR codes avec le nouveau token dans qrcodes.html
4. Mettez à jour aussi TOKEN_SECRET dans index.html
