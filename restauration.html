Cette page remet en place les données d'une sauvegarde automatique (fichier Sauvegarde_Auto_AAAA-MM-JJ.json, dans Google Drive › « Sauvegardes applis »).
Chaque document est réécrit à l'identique (même identifiant, mêmes dates, mêmes nombres). Un document qui existe déjà avec le même identifiant est remplacé par celui de la sauvegarde ; les documents plus récents que la sauvegarde ne sont pas effacés.

🆘 Après une restauration : si une liste reste vide

Les données sont dans la sauvegarde, mais pas les index (le « classement » que Firebase prépare pour certaines listes). Sur une base neuve ou de test, une appli peut donc afficher une liste vide alors que tout est bien là. Pour le réparer, une seule fois par base :
  1. Ouvre l'appli qui reste vide, appuie sur F12 → onglet Console.
  2. Cherche un message rouge « The query requires an index » et clique sur le lien bleu qui commence par https://console.firebase.google.com/…create_composite=.
  3. Firebase s'ouvre avec l'index déjà rempli : clique sur Créer, attends 1 à 3 minutes (« Activé »), puis recharge l'appli (Ctrl + F5).
Index connus : Pointeuse / Planning → collection employees : active croissant + name croissant.

Ce que la sauvegarde ne contient pas (à refaire à la main sur une base neuve) : les règles de sécurité (fichiers regles-firestore-….txt), les comptes de connexion (Authentication), les photos et documents (Storage). Le code des applis est sur GitHub.
